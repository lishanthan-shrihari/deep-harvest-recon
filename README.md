# 🌾 Deep-Harvest: Automated Historical Archive Reconnaissance Pipeline

**Deep-Harvest** is a robust, automated Bash reconnaissance utility developed in **Void Labs** designed to act as the downstream consumer for perimeter discovery pipelines (such as Project 1: **Eagle-Eye**). 

While active reconnaissance maps out what is online *today*, Deep-Harvest looks backward in time across public internet archives to unearth thousands of forgotten web pages, hidden API endpoints, backup files, and historical parameters.

---

## 🚀 Key Features

* **Pipeline Interoperability**: Seamlessly ingests machine-readable clean domain lists generated by active reconnaissance phases (`live_domains_for_harvest.txt`).
* **Automated Data Sanitization**: Utilizes stream editors (`sed`) and column splitters (`cut`) to clean incoming URLs, stripping out protocol prefixes (`http://`, `https://`) and trailing URI paths.
* **IP Address Safety Filter**: Incorporates a strict Regular Expression (Regex) safety check to intercept and discard raw IPv4 addresses, ensuring only valid domain names are queried against archives.
* **Batch Historical Mining**: Integrates with **`waymore`** to automate large-scale historical endpoint harvesting across public databases (Wayback Machine, Common Crawl, URLScan).
* **Structured Output Architecture**: Automatically organizes harvested endpoints into individual domain-specific text files inside a dedicated `harvest_results/` directory.
